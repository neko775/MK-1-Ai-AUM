# MK 1 AI AUM — 超軽量・オールインワン エアギャップ自動遮断AI (v2)

世の中のサイバー詐欺やウイルス感染被害を少しでも減らしたいという強い正義感とロマンを元に、13歳の個人開発者が設計した、絶対無停止の次世代ネットワーク防衛システムです。

##  本プロジェクトの配信思想（知的財産保護と悪用防止）
本システム「MK 1 AI AUM」は、世界中のユーザーが完全無料で安心してダウンロードして利用できるよう、GitHub上でパブリック公開を行っています。
ただし、本システムの高度な防衛ロジックが詐欺師や悪意あるハッカーにリバースエンジニアリングされ、偽のセキュリティ対策ソフト（偽陽性詐欺ツール）などに悪用される二次被害を根本から排除するため、**ソースコードの生データは公開せず、完全なブラックボックス（暗号化ファイル）の状態で安全に配信**しています。

### 【ガチガチのトリプルロック（多要素）起動シークエンス】
暗号化された本システムを解凍し、安全に起動・検査するには、以下の3つの認証（物理・生体・暗号）をクリアすることが論理的・物理的に必須となります。

1. **物理認証 (USB):** コアシステムが封印された専用の物理USBドライブ「MK1_CORE」が本体に直接接続されていること。
2. **生体認証 (iPhone 14):** 開発者本人の持つ iPhone 14 の「Face ID（顔認証）」に成功すること。
3. **耐量子ハイブリッド暗号 (AES-256-GCM to PQC):** iPhoneのSecure Enclaveからネットワーク経由で送信される一時的な検証トークンと、改ざんを1ビットも許さない「AES-256-GCM」、および将来の量子コンピュータによる解析を無力化する格子暗号ベース（PQC）の多層ディフェンスをクリアすること。

認証成功時、プログラムはパソコンのストレージ（SSDなど）に1ミリも生データを残さず、システムRAM（メモリ）の上だけでJIT的に展開・実行（エアギャップ防衛）されます。これにより、国や大企業であってもコードを複製・横取りすることは理論上不可能です。

##  システムの仕様（Chromebookエコ設計）
開発環境である **「Intel N100 CPU / 4GB RAMのChromebook」** の限られたパワーを極限まで引き出し、絶対にクラッシュ（OOM）させないために設計された超軽量アーキテクチャです。

- **RAM監視基準:** 上限 500MB
- **3層リソース構造:** 
  - `Layer 1 (Googleドライブ)`: 100GBのクラウド領域を教材（ハッキングデータ）の保管庫とする。
  - `Layer 2 (ローカルストレージ)`: メモリを圧迫しないよう、暗号化した `mmap`（仮想メモリ）によるリングバッファを構築し、緊急データを退避。
  - `Layer 3 (システムRAM)`: 実行現場のRAM上限を「500MB」に厳格にキープし、本体のクラッシュを絶対防止。
- **マルチタスクAI:** 
  - 単一のニューラルネットワーク（PyTorch）に「防衛（Head A）」「学習・厳選（Head B）」「システム管理（Head C）」という3つの役割を同時にこなさせ、メモリ消費を約3分の1に抑制。
  - ローカル学習（通常学習・RSI学習）時には、既存の防衛知識を破壊しないよう、Head B以外の重みを凍結（フリーズ）して破滅的忘却を防止。
- **検知ロジック:** 未知の暗号化パケット（AES/PQC）のパケット長分布、時間間隔、ジッタ周期性によるメタデータ行動異常検知。
